## 一、系统架构

```
┌──────────────────────────────────────────────────────────┐
│  浏览器                                                   │
│  ├─ localhost:8088  Superset 仪表板                       │
│  ├─ localhost:5000  ECharts 数据大屏                       │
│  └─ localhost:8501  Streamlit 智能问答                     │
└──────────────────────────────────────────────────────────┘
        │                    │                    │
        ▼                    ▼                    ▼
   ┌─────────┐        ┌──────────┐        ┌────────────┐
   │ Superset │        │ web(Flask)│        │ app(Streamlit)│
   └────┬────┘        └─────┬────┘        └──────┬─────┘
        │                   │                    │ docker exec
        └────────┬──────────┘                    ▼
                 ▼                        ┌──────────────┐
          ┌────────────┐                  │ hive-server  │
          │   MySQL    │◀───同步──────────│  (Hive 4.0)  │
          │ BI 集市    │                   └──────┬───────┘
          │ + 元数据    │                          ▼
          └────────────┘                  ┌──────────────┐
                                          │hive-metastore│
                                          └──────────────┘
```

**核心设计**：Hive 负责计算（ODS→DWD→DWS→ADS），结果同步到 MySQL 集市，BI 与应用层只读 MySQL。
原因：Superset/Flask 直连 Hive 需要 `pyhive + thrift + sasl`（sasl 需 C 编译），容器内失败率高。

## 二、服务清单

| 服务 | 容器名 | 端口 | 说明 |
|---|---|---|---|
| mysql | hive-project-mysql-1 | 3306 | BI 集市（`ydsh_ads`）+ Superset 元数据（`superset`） |
| hive-metastore | hive-project-hive-metastore-1 | 9083 | Hive 元数据服务 |
| hive-server | hive-project-hive-server-1 | 10000 / 10002 | HiveServer2（beeline 入口） |
| superset | hive-project-superset-1 | 8088 | 仪表板（admin / admin123） |
| web | hive-project-web-1 | 5000 | ECharts 大屏 + Flask JSON 接口 |
| app | hive-project-app-1 | 8501 | Streamlit 问答（挂 docker.sock 调 beeline） |

依赖关系：`mysql` 健康 → `hive-metastore` → `hive-server`；`superset`、`web` 依赖 mysql 健康；`app` 依赖 hive-server 与 web。

## 三、首次部署（从零到可访问）

### 3.1 前置条件

- Docker Desktop（Windows 需开启 WSL2 后端）
- 端口 3306 / 5000 / 8088 / 8501 / 9083 / 10000 / 10002 未被占用
- 磁盘 ≥ 15 GB（镜像：hive 2.8 GB、superset ~1 GB、mysql 1.1 GB）

### 3.2 准备密钥文件

在项目根目录创建 `.env`（**不要提交 Git**，已在 `.gitignore`）：

```
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
SUPERSET_SECRET_KEY=任意 40 位随机字符串
```

### 3.3 一键启动

```powershell
cd E:\hive-project
docker compose up -d
docker compose ps
```

首次启动需构建 superset / web / app 三个镜像（约 5~8 分钟）。

### 3.4 初始化（仅首次）

```powershell
# 1) 建 Superset 元数据库
docker exec hive-project-mysql-1 mysql -uroot -proot -e "CREATE DATABASE IF NOT EXISTS superset DEFAULT CHARACTER SET utf8mb4;"

# 2) Superset 初始化
docker exec hive-project-superset-1 superset db upgrade
docker exec hive-project-superset-1 superset fab create-admin --username admin --firstname Admin --lastname User --email admin@example.com --password admin123
docker exec hive-project-superset-1 superset init

# 3) 导入 ODS 数据（见第 1 周脚本）
docker cp sql/ods/. hive-project-hive-server-1:/sql/ods/
docker exec hive-project-hive-server-1 beeline -u "jdbc:hive2://localhost:10000/" -f /sql/ods/create_ods.sql

# 4) 建 DWD / DWS / ADS
#   依次执行 sql/clean/、sql/dwd/、sql/dws/、sql/ads/ 下脚本

# 5) 同步到 MySQL 集市
.\.venv\Scripts\python.exe sync\sync_ads_to_mysql.py
cmd /c 'docker exec -i hive-project-mysql-1 mysql -uroot -proot --default-character-set=utf8mb4 < "E:\hive-project\sql\mysql\init_ydsh_ads.sql"'

# 6) 注册 Superset 数据集与图表
.\.venv\Scripts\python.exe superset\setup_superset.py
.\.venv\Scripts\python.exe superset\setup_charts.py
```

### 3.5 验证

| 检查项 | 命令 / 地址 | 期望 |
|---|---|---|
| 容器状态 | `docker compose ps` | 6 个服务 Up（4 个 healthy） |
| Hive 连通 | `docker exec hive-project-hive-server-1 beeline -u "jdbc:hive2://localhost:10000/" -e "show databases"` | 列出 ydsh_ods/ydsh_dwd/ydsh_dws/ydsh_ads |
| MySQL 集市 | `docker exec hive-project-mysql-1 mysql -uroot -proot -e "select count(*) from ydsh_ads.ads_sales_daily"` | 366 |
| Superset | http://localhost:8088 | 能登录，仪表板 6 图正常 |
| 大屏 | http://localhost:5000 | 6 个图表 + 地图渲染 |
| 问答 | http://localhost:8501 | 提问能返回 SQL 与结果 |

## 四、日常运维

```powershell
docker compose ps                    # 状态
docker compose logs -f superset      # 查看日志
docker compose restart web           # 重启单个服务
docker compose up -d --build app     # 改代码后重建
docker compose down                  # 停止（保留数据卷）
```

**注意**：不要执行 `down -v`，会删除 MySQL 数据卷，Hive 元数据与集市数据全部丢失。

## 五、常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 容器 Exited (1) 反复重启 | HiveServer2 pid 残留 | 已通过 `HIVESERVER2_PID_DIR=/tmp/hive-pid` + tmpfs 根治；仍失效则 `docker compose up -d --force-recreate hive-server` |
| Superset 打不开 | 元数据库未初始化 | 重新执行 `superset db upgrade` |
| 仪表板显示"没有关联图表" | `dashboard_slices` 缺关联 | 执行 `superset/setup_charts.py` 重建，或补插关联记录 |
| 柱状图报 `Datetime column not provided` | 数据集主时间列配置不当 | 分类轴图表改用 `dist_bar` |
| 大屏图表空白 | Flask 接口取不到数据 | 访问 `/api/kpi` 排查；确认 MySQL 集市已导入 |
| Streamlit 提问报"docker 命令不存在" | 容器内缺 docker CLI 或未挂 socket | 确认 compose 中挂载 `/var/run/docker.sock` 且镜像装了 `docker.io` |
| 端口冲突（3306/8501/5000/8088） | 本机已有服务占用 | 停掉占用进程，或修改 compose 端口映射 |
| 中文乱码 | 编码未统一 | 脚本开头 `chcp 65001`、`PYTHONIOENCODING=utf-8`、MySQL 连接 `charset=utf8mb4` |
