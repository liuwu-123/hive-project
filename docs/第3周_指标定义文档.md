# 第 3 周 · 指标定义文档

> 团队：云仓五号　版本：v1.0　日期：2026-11-10
> 用途：统一 KPI 口径，保证「不同人跑同一指标得出同一数字」

---

## 一、为什么先写这份文档

第 3 周部署手册把「指标口径不清」列为第一难点，原话是：

> 不同人算出不同 GMV → 应对策略：先写《指标定义文档》统一口径

在实际开发中确实出现过口径分歧：品类销售额（明细口径）合计约 5.1 亿，而订单实付 GMV 只有 3,595 万，相差 14.21 倍。**如果不先定义清楚，两个数字都会被当作「GMV」汇报。**

---

## 二、核心 KPI 定义

| 指标 | 英文/字段 | 口径（计算公式） | 数据源 | 过滤条件 |
|---|---|---|---|---|
| GMV | `gmv` | `SUM(pay_amount)` | `ydsh_dwd.fact_order` | `amount_invalid = 0` |
| 订单量 | `order_cnt` | `COUNT(DISTINCT order_id)` | `ydsh_dwd.fact_order` | `amount_invalid = 0` |
| 客单价 | `aov` | `GMV ÷ 订单量` | 同上 | 同上 |
| 活跃用户数 | `buyer_cnt` | `COUNT(DISTINCT user_id)` | `ydsh_dwd.fact_order` | `amount_invalid = 0` |
| 复购率 | `repurchase_rate` | 下单 ≥2 次用户数 ÷ 下单用户数 | `ydsh_dwd.fact_order` | `amount_invalid = 0` |
| 品类销售额 | `sales` | `SUM(item_amount)` | `ydsh_dwd.fact_order_item` | `qty_invalid = 0` |
| 品类销量 | `qty` | `SUM(quantity)` | `ydsh_dwd.fact_order_item` | `qty_invalid = 0` |
| 用户累计消费 | `total_amount` | 按 `user_id` 汇总 `pay_amount` | `ydsh_dwd.fact_order` | `amount_invalid = 0` |

### 关键约定

1. **「有效订单」的唯一定义**：`fact_order.amount_invalid = 0`，即已排除负金额（310 条）与超过 10 万元的异常值（312 条）。任何涉及 GMV、订单量、客单价的指标都必须带这个条件。
2. **金额单位统一为元**，保留 2 位小数；比率保留 4 位小数。
3. **时间字段**：订单时间用 `order_timestamp`（格式 `yyyy-MM-dd HH:mm:ss`），按月分区字段是 `order_month`（格式 `yyyy-MM`）。

---

## 三、两个必须说明的口径问题

### 3.1 品类销售额与订单 GMV 不可相加（差异 14.21 倍）

| 口径 | 金额 | 说明 |
|---|---|---|
| 订单实付 GMV | 35,948,606.01 元 | `fact_order.pay_amount`，是用户实际支付的钱 |
| 明细商品金额 | 510,877,914.27 元 | `fact_order_item.item_amount`，约 14.21 倍 |
| 订单-明细覆盖度 | 99.53% | 14,398 笔有效订单中 14,330 笔有明细（68 笔缺失） |

**结论**：两个数分别代表「实付」与「原价/折扣前」两种业务口径，**不能相加，也不能互相校验**。品类分析只能用明细口径，且必须在报告中注明，避免与 GMV 混用。

**待办**：该差异已登记为 Issue（见仓库 Issues），第 4 周需核对业务规则确认。

### 3.2 复购率 100% 不是错误

| 统计项 | 数值 |
|---|---|
| 下单用户数 | 1,000 |
| 下单 ≥2 次用户数 | 1,000 |
| 复购率 | 100% |
| 单用户最少订单数 | 4 笔 |
| 单用户最多订单数 | 27 笔 |
| 单用户平均订单数 | 14.4 笔 |

**结论**：本数据集为合成数据，每个用户都有多次下单，不存在只买一次的用户，因此复购率必然为 100%。该指标在当前数据上**没有区分度**，真实业务应改用「90 天内复购率」等时间窗口口径。

## 四、指标与表的对应关系

| 指标 | 计算层 | 落表 |
|---|---|---|
| GMV / 订单量 / 客单价 / 活跃用户 / 复购率 | ADS | `ydsh_ads.ads_kpi_overview` |
| 日 GMV / 订单量 / 日环比 | DWS → ADS | `ydsh_dws.dws_sales_day` → `ydsh_ads.ads_sales_daily` |
| 月 GMV / 取消率 / 退款率 | DWS | `ydsh_dws.dws_sales_month` |
| 品类销售额 / 占比 | DWS → ADS | `ydsh_dws.dws_category_month` → `ydsh_ads.ads_category_topn` |
| 门店 GMV / 排行 | DWS → ADS | `ydsh_dws.dws_store_month` → `ydsh_ads.ads_store_topn` |
| 用户累计消费 / 分层 | ADS | `ydsh_ads.ads_user_value` |

---

## 五、验证方式

任何指标复现时，按以下三步核对：

1. 先查 `ydsh_ads.ads_kpi_overview`，看口径说明字段；
2. 用本文档的公式在 `ydsh_dwd` 明细层重算一遍，两个结果应完全一致；
3. 若不一致，优先检查是否漏了 `amount_invalid = 0` / `qty_invalid = 0` 条件。
